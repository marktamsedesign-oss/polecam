Points

Export

Punchlist · Excel

Sheet 1: numbered deficiency list (location, element, defect, severity, status, dates, photo names). Sheet 2: every element inspected with MLoop / NAP / closure / ODF details.

Punchlist report · PDF

Summary, numbered punchlist, sign-off boxes for Globe and contractor, then photos of each element and each defect.

Rectification report · PDF

How the contractor cleared the punchlist: each item's before and after photos with the time, GPS and person recorded when each photo was taken, days to rectify, progress by date, items cleared without photo evidence, and sign-off.

Google Earth · KMZ

Pins by status (red: open deficiency, blue: rectified, green: OK), with details and photos in each balloon.

Punchlist · CSV

Same table as the Excel punchlist, for your acceptance tracker.

Google Earth · KMZ

Pins named by Pole ID, with the photo inside each pin's balloon.

AutoCAD · DXF

Poles as blocks (POLE_<TYPE>) at UTM 51N meters, Pole ID labels on layer POLE_LABEL. Redefine a block in AutoCAD to swap in your own pole symbol.

Table · CSV

Pole ID, type, lat/long, UTM easting/northing, accuracy, time. Opens in Excel or QGIS.

Geotagged photos · ZIP

JPEGs named by ID, stamped with ID, coordinates and time, with GPS written into the photo (EXIF).

Backup

Everything in this project (points and photos) in one file. Restore it on another phone or after reinstalling.
