Photo checks

A photo is taken only when the GPS updated within the last 5 seconds (green shutter). Dark, blank and blurry photos are refused and must be retaken.

Online street map

      
Street tiles come from a free map server. On “Automatic” the app moves to the next server when one stops answering. If the map stays blank, run the test below and send the result to your admin.

Offline map packs

      
A map pack is a street map of a whole area kept on this phone: roads, buildings, rivers and place names, sharp at every zoom. Get it once on Wi-Fi. When there is no signal the app switches to it by itself; the layers button also switches to it.

The Drive file must be shared as “Anyone with the link”. The Android app downloads it directly; the website version opens it in Drive so you can download it and import it here.

      

    

    

      
Map tiles you have viewed

      
Street map tiles you look at while online are kept on the phone for 7 days and shown again without signal. Satellite imagery is not kept: Esri allows offline imagery only in its own ArcGIS apps. Use a map pack for areas you have not viewed.

Field standards

        

        
        
        
        
      

      

        
Shared KMZ lock (PAT, defect cleanup, FAT)

        
The G-eSAA data inside the KMZ files shared for the defect cleanup and the FAT (records, deficiencies, photos) is locked with this password. Google Earth still shows the map; the data can be read only by G-eSAA phones that have this company list, and a file whose data was changed is refused. Every phone gets the password with the list: nobody types it. Survey KMZ, backups and other exports are not locked.

        
        

      

      

        
Approve a delete

        
A user deleting a completed project gets a request code. Type it here and give them the 6-digit approval code; it works only for that request.

        

        

      

      

        
Offline map packs

        
Upload each .pmtiles map pack to Google Drive and share it as “Anyone with the link”. Paste one line per pack: name | Drive link | size in MB. Users see these packs under Maps after they take this list version (join link or QR code), or after Refresh list when the online sheet is connected. Users cannot add links themselves.
